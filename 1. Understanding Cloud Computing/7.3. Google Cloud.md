# 7.3. Google Cloud

## Google Cloud Platform (GCP) Overview & Case Study

Google Cloud Platform emphasizes open-source technologies and hybrid multi-cloud management to prevent vendor lock-in.

## 1. Market Position & Multi-Cloud Focus

- **Multi-Cloud Strategy:** Google Cloud embraces multi-cloud architecture, acknowledging that modern organizations prefer not to be locked into a single provider.
    
- **Google Cloud Anthos:** Launched in 2019, Anthos enables users to manage, deploy, and run workloads seamlessly across on-premises servers and multiple public clouds using a single interface.
    
- **Market Share:** Held **11% of the cloud market share** by the end of 2023, positioning it as the third-largest provider behind AWS and Azure.
    
- **Notable Clients:** Major corporate clients include PayPal, HSBC, and Vodafone.
    

## 2. Key Google Cloud Services

### Core Infrastructure Services

- **Google Cloud Storage:** Object and file storage.
    
- **Google Cloud Compute Engine:** Scalable virtual machine instances.
    
- **Google Cloud SQL:** Fully managed relational database service.
    

### Big Data & Machine Learning Services

- **BigQuery:** Serverless, highly scalable cloud data warehouse for massive data analytics.
    
- **Dataflow:** Fully managed streaming and batch data processing service.
    
- **AutoML:** A suite of machine learning tools allowing users to train custom high-quality models.
    

## 3. Case Study: Lush Cosmetics

### The Challenge

UK cosmetics retailer **Lush** faced recurring website crashes during peak shopping periods like Boxing Day. Their legacy infrastructure capped out at just 12 transactions per second, failing to handle high customer traffic.

### The GCP Solution

Lush migrated its entire operational infrastructure—including 17 websites, mobile apps, e-commerce platforms, customer databases, and product systems—to Google Cloud during December (their peak sales month). They utilized **Compute Engine** for agile testing and deployment, while moving underlying data to **Google Cloud SQL**.

### Results & Business Impact

- **Zero Downtime:** Successfully processed peak Boxing Day shopping traffic without any server outages or performance bottlenecks.
    
- **Cost Reduction:** Achieved a **40% reduction** in overall hosting costs.
    
- **Innovation:** Leveraged GCP capabilities to build an image-recognition mobile application that identifies unpackaged ("naked") products and displays ingredient/usage details directly to customers.

    - _Answer:_ BigQuery.
        
3. **What financial benefit did Lush achieve after migrating its e-commerce infrastructure to Google Cloud?**
    
    - _Answer:_ A 40% reduction in hosting costs alongside zero outages during peak sales periods.
