# 7.2. Microsoft Azure

Microsoft Azure is a major cloud service provider known for its seamless integration with legacy Microsoft products and strong enterprise security features.

## 1. Market Position & Integration

- **Enterprise Integration:** Microsoft expanded into the cloud by adapting core products—such as Office, Windows Server, and SQL Server—for cloud environments.
    
- **Customer Loyalty:** Strong brand recognition and existing Microsoft enterprise contracts drive adoption among organizations already reliant on Microsoft software.
    
- **Market Share:** Held **24% of the total cloud market share** by the end of 2023, ranking second behind AWS.
    
- **Notable Clients:** Includes global institutions and enterprises like Siemens, The World Bank, and L'Oréal.
    

## 2. Key Azure Services

### Core Infrastructure Services

- **Azure Blob Storage:** Object and file storage.
    
- **Azure Virtual Machines:** On-demand compute instances.
    
- **Azure SQL Database:** Managed relational database services.
    

### Unified Analytics & Data Services

- **Microsoft Fabric:** An end-to-end SaaS platform that unifies data movement, data science, real-time analytics, and business intelligence.
    
- **Azure Data Lake Storage:** Scalable storage designed for raw data ingestion prior to processing.
    
- **Azure Stream Analytics:** Real-time stream processing and event analytics.
    
- **Azure Machine Learning:** End-to-end ML model development, training, and deployment.
    

## 3. Case Study: The Ottawa Hospital

### The Challenge

The Ottawa Hospital—managing millions of patient records across multiple sites—needed a cost-effective **disaster recovery** plan. Maintaining a secondary physical, on-premises disaster recovery site was too expensive.

### The Azure Solution

The hospital opted for a **hybrid approach**:

- Kept primary health records on-premises for cost efficiency.
    
- Utilized **Azure IaaS** to build a secure, scalable secondary site in the cloud.
    
- Leveraged **Azure Storage** for medical imaging files and **Azure Site Recovery** for automated failover during potential outages or cyberattacks.
    
- Maintained continuous database synchronization to ensure backups remained up to date.
    

### Results & Business Impact

- **Cost Savings:** Reduced disaster recovery costs by **50%** compared to an on-premises alternative.
    
- **High Capacity:** Successfully backed up **700 terabytes** of sensitive health data while supporting up to 5,300 concurrent users.
    
- **Rapid Deployment:** Fully implemented the solution in **under 3 months**.
    
- **Regulatory Compliance:** Met all strict Canadian healthcare privacy laws, including the Personal Health Information Protection Act (PHIPA).
    

### Quick Review Questions

1. **What strategic advantage helps Microsoft Azure retain and acquire enterprise customers?**
    
    - _Answer:_ Tight integration with existing Microsoft business software, such as Windows Server, SQL Server, and Office.
        
2. **What is Microsoft Fabric?**
    
    - _Answer:_ A Software as a Service (SaaS) platform that unifies Microsoft's data ingestion, data science, analytics, and business intelligence tools.
        
3. **How did The Ottawa Hospital cut disaster recovery costs by 50%?**
    
    - _Answer:_ By using a hybrid setup—keeping primary databases on-premises while using Azure IaaS and Azure Site Recovery for automated cloud failover.
