# 7.1. Amazon Web Services

AWS is the pioneer and leading cloud service provider globally, offering an extensive range of cloud infrastructure and data services.

## 1. Market Position & Capabilities

- **First-Mover Advantage:** Launched in 2006 (two years before Google Cloud and four years before Microsoft Azure).
    
- **Market Share:** Stood as the market leader with 31% of total cloud market share by the end of 2023.
    
- **Service Ecosystem:** Offers over 175 cloud services across computing, storage, analytics, security, enterprise apps, and machine learning.
    
- **Notable Clients:** Enterprise customers across diverse industries include Disney, Verizon, and Deloitte.
    

## 2. Key AWS Services

### Core Infrastructure Services

- **Amazon S3 (Simple Storage Service):** Object and file storage.
    
- **Amazon EC2 (Elastic Compute Cloud):** Virtual compute instances/servers.
    
- **Amazon RDS (Relational Database Service):** Managed relational database management.
    

### Data & Machine Learning Services

- **Amazon Redshift:** Fully managed, petabyte-scale cloud data warehousing.
    
- **Amazon Kinesis:** Real-time streaming data ingestion and analytics.
    
- **Amazon SageMaker:** End-to-end platform for building, training, and deploying machine learning models.
    

## 3. Case Study: NerdWallet

### The Challenge

Personal finance platform NerdWallet needed to speed up its machine learning deployment lifecycle. Moving predictive models from concept to production took too long, hindering product iterations and increasing costs.

### The AWS Solution

Already utilizing Amazon compute and container infrastructure, NerdWallet integrated **Amazon SageMaker** to unify model building, training, and deployment within a single ecosystem.

### Results & Business Impact

- **Accelerated Time-to-Market:** Model deployment times were reduced from **months to days**.
    
- **Cost Reduction:** Machine learning training costs dropped by **75%** by leveraging SageMaker's on-demand compute instances rather than maintaining continuously running hardware.
    
- **Developer Productivity:** Data scientists shifted focus away from infrastructure management to strategy and innovation.
    

### Quick Review Questions

1. **What primary advantage allowed AWS to capture 31% of the cloud market by late 2023?**
    
    - _Answer:_ Its first-mover advantage, launching in 2006 ahead of major competitors.
        
2. **Which AWS service provides fully managed, petabyte-scale data warehousing?**
    
    - _Answer:_ Amazon Redshift.
        
3. **How did Amazon SageMaker reduce ML training costs for NerdWallet by 75%?**
    
    - _Answer:_ By utilizing on-demand compute instances that only run when models are actively training, rather than paying for continuous server uptime.
