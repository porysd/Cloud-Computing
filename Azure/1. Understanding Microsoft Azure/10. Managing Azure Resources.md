# 10. Managing Azure Resources

This section explores the administrative tools and frameworks used to deploy, automate, monitor, and govern infrastructure across Microsoft Azure.

**1. Azure Resource Manager (ARM) & Governance Tools**

- **Azure Resource Manager (ARM):** The central management layer for Azure. Handles resource creation, updates, and deletion through a unified API. Supports declarative ARM/Bicep templates for repeatable deployments and resource tagging for organizational structure and cost tracking.
    
- **Azure Policy:** Enforces compliance and governance across organizational subscriptions by blocking non-compliant resource creations or auditing existing configurations (e.g., restricting allowed regions to comply with data sovereignty regulations like GDPR).
    
- **Azure Blueprints (Modern Equivalent: Deployment Stacks & Template Specs):** Packages resource templates, RBAC assignments, and Azure Policy definitions into a single, versioned setup unit to ensure enterprise consistency across environments. _(Note: Azure Blueprints is scheduled for retirement on January 31, 2027; Microsoft recommends migrating blueprint definitions to Azure Deployment Stacks)._
    

**2. Azure Operations, Monitoring & Automation**

|**Management Tool**|**Primary Core Function**|**Key Capabilities & Artifacts**|
|---|---|---|
|**Azure Monitor**|Full-stack performance monitoring & telemetry collection|Real-time metrics, log analytics, continuous app monitoring, and automated operational alerts.|
|**Azure Automation**|Task automation & configuration management|Uses **Runbooks** (PowerShell/Python) for scheduled maintenance, patch management, and hybrid resource configuration.|
|**Azure Advisor**|Personalized best practices engine|Generates tailored recommendations across 5 pillars: **Cost**, **Security**, **Reliability**, **Performance**, and **Operational Excellence**.|

**Quick Review Questions**

1. **What is the central service in Azure that receives and processes all API requests for creating, updating, and deleting resources?**
    
    - **Answer:** Azure Resource Manager (ARM).
        
2. **How does Azure Policy help organizations maintain regulatory compliance (such as GDPR or HIPAA)?**
    
    - **Answer:** It defines and enforces specific operational constraints—such as mandating resource deployment within designated geographic regions or enforcing mandatory security settings—and flags or blocks non-compliant deployments automatically.
        
3. **What is an Azure Automation "Runbook"?**
    
    - **Answer:** A routine operational script (written in PowerShell or Python) that automates repetitive management, configuration, and maintenance tasks within Azure or hybrid IT environments.
        
4. **What modern Azure service replaces Azure Blueprints for orchestrating grouped deployments with lock protection?**
    
    - **Answer:** **Azure Deployment Stacks** (paired with Template Specs).
