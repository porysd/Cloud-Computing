# 8. Security and Compliance in Azure

This section outlines Azure's core defense mechanisms, compliance framework tools, data protection standards, role-based access controls, network security features, and threat monitoring platforms.

**1. Governance, Risk, and Compliance (GRC) Tools**

- **Azure Policy:** Enforces organizational standards and assesses compliance across Azure subscriptions at scale (e.g., blocking non-compliant resource deployments, restricting geographic regions, or enforcing GDPR audit baselines).
    
- **Microsoft Defender for Cloud (formerly Azure Security Center):** Provides centralized Cloud Security Posture Management (CSPM) and threat protection across hybrid and multi-cloud environments. Evaluates resource configurations to continuously compute a overall **Secure Score**.
    
- **Azure Blueprints:** Packages resource templates, RBAC assignments, and Azure Policy definitions into a repeatable deployment unit to ensure enterprise-wide consistency.
    

**2. Data Protection & Identity Controls**

### Data Encryption

- **Encryption at Rest:** Protects stored data on physical media (disks, databases, backups) using **AES-256** standard (analogous to storing money in a vault).
    
- **Encryption in Transit:** Protects data moving across networks via **TLS/HTTPS** protocols (analogous to transporting money in an armored truck).
    

### Azure Role-Based Access Control (Azure RBAC)

Azure RBAC operates on the **Principle of Least Privilege**, granting identities (users, groups, service principals) only the precise permissions required.

|**Key Built-In Role**|**Permission Scope**|
|---|---|
|**Owner**|Full access to manage all resources, including the ability to grant/assign permissions to others.|
|**Contributor**|Full access to manage all resources, but **cannot** grant permissions to other users.|
|**Reader**|View-only access to inspect resources without making changes.|
|**User Access Administrator**|Manages user access and permissions to Azure resources without full resource control.|

**3. Network & Application Security**

```
 [ External Internet ]
         │
         ▼
 [ Azure DDoS Protection ]   ── Flushes malicious traffic bursts (Layer 3/4)
         │
         ▼
  [ Azure Firewall ]         ── Stateful filtering & domain inspection (Layer 4/7)
         │
         ▼
[ Network Security Group ]   ── Inbound/Outbound IP & Port filtering rules (Subnet/NIC)
         │
         ▼
 [ Azure Resources / VMs ]
```

- **Network Security Groups (NSGs):** Stateful packet-filtering firewalls applied at the subnet or Network Interface Card (NIC) level to allow/deny specific inbound and outbound IP address, port, and protocol traffic.
    
- **Azure Firewall:** Managed, cloud-based network security service that provides stateful traffic inspection, threat intelligence, and centralized URL/FQDN filtering.
    
- **Azure DDoS Protection:** Continuous threat monitoring and real-time mitigation that absorbs massive distributed denial-of-service volumetric attacks before they reach application resources.
    

**4. Specialized Security & Key Management Services**

- **Azure Key Vault:** Centralized, hardware-backed repository for securely managing cryptographic keys, API tokens, database connection strings, and certificates.
    
- **Microsoft Purview Information Protection (formerly Azure Information Protection):** Classifies, labels, and encrypts sensitive organizational documents and emails across cloud repositories.
    
- **Microsoft Sentinel:** Cloud-native **SIEM** (Security Information and Event Management) and **SOAR** (Security Orchestration, Automation, and Response) engine that ingests logs across all cloud assets to automate threat detection and incident response.
    

**Quick Review Questions**

1. **What is the key difference between the Owner role and the Contributor role in Azure RBAC?**
    
    - **Answer:** Both roles can manage all Azure resources, but an **Owner** can assign/grant permissions to other users, whereas a **Contributor** cannot.
        
2. **At what boundary level do Network Security Groups (NSGs) filter network traffic?**
    
    - **Answer:** At the individual Network Interface Card (NIC) or Subnet level within an Azure Virtual Network (VNet).
        
3. **Which Azure service provides centralized secret management for API keys, passwords, and TLS certificates?**
    
    - **Answer:** Azure Key Vault.
        
4. **How do Azure Policy and Azure Blueprints complement each other in corporate governance?**
    
    - **Answer:** Azure Policy enforces operational rules and compliance standards, while Azure Blueprints packages those policies alongside resource templates and access controls into a single repeatable deployment setup.
