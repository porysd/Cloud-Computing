# 11. Integration and Migration to Azure

**Integration and Migration to Azure**

This section breaks down the **3-step cloud migration roadmap**, the **4 primary application integration strategies (5 Rs)**, **hybrid networking connectivity options**, and essential Azure migration services (**Azure Migrate**, **Azure Site Recovery**, and **Azure Database Migration Service**).

**1. Cloud Integration Strategies (The Migration Spectrum)**

Choosing the correct migration path balances time-to-market against long-term operational efficiency:

```
[ Rehost ] ──────► [ Refactor ] ──────► [ Rearchitect ] ──────► [ Rebuild ]
 (Lift & Shift)     (Minimal Code)      (Cloud-Native)       (Fresh Start)
   Speed: High        Speed: Med          Speed: Low          Speed: Very Low
   Effort: Low        Effort: Med         Effort: High        Effort: Highest
```

- **Rehost (Lift and Shift):** Moves applications directly from physical/virtual servers to Azure VMs without code modifications. Fast with low initial cost, but doesn't take full advantage of cloud-native scalability.
    
- **Refactor (Repackage):** Applies minimal code or configuration tweaks to leverage cloud platform services (e.g., moving a web app into Azure App Service) with minimal effort.
    
- **Rearchitect:** Redesigns an application’s architecture for cloud-native features (e.g., breaking monolithic architectures into microservices using Azure Kubernetes Service or Functions).
    
- **Rebuild:** Discards existing legacy codebases and develops a new cloud-native application from scratch on Azure services. Highest effort, but completely modernizes outdated systems.
    

**2. Azure Hybrid Connectivity & Migration Tools**

|**Tool / Service**|**Category**|**Core Purpose**|**Key Characteristics**|
|---|---|---|---|
|**VPN Gateway**|Hybrid Network|Encrypted connection over the public internet|Connects on-premises networks to Azure via S2S IPsec/IKE tunnels.|
|**Azure ExpressRoute**|Hybrid Network|Private, direct circuit bypassing the internet|Delivers lower latency, higher security, and consistent throughput up to 100 Gbps.|
|**Azure Virtual WAN**|Hybrid Network|Automated global branch networking|Integrates site-to-site VPNs, ExpressRoute, and branch links into a single hub-and-spoke network.|
|**Azure Migrate**|Migration Platform|Unified discovery, assessment, and migration|Provides centralized management, workload inventory, sizing recommendations, and cost estimates.|
|**Azure Site Recovery (ASR)**|Disaster Recovery|Business continuity & workload replication|Automates VM protection and failover/failback during outages or migration cutovers.|
|**Azure Database Migration Service (DMS)**|Database Tool|Schema and data synchronization|Enables online/offline database migration (SQL, MySQL, PostgreSQL, MongoDB) with near-zero downtime.|

**Quick Review Questions**

1. **Which migration strategy ("Lift and Shift" / Rehost vs. Rebuild) presents the lowest immediate technical friction for moving an existing server directly into Azure?**
    
    - **Answer:** **Rehost (Lift and Shift)**, because it transfers workloads to Azure Infrastructure as a Service (IaaS) without altering application code or underlying OS configurations.
        
2. **What is the primary operational advantage of Azure ExpressRoute over a standard Azure VPN Gateway?**
    
    - **Answer:** ExpressRoute provides a dedicated, private connection that bypasses the public internet entirely, delivering higher reliability, faster speeds, lower latency, and tighter security.
        
3. **Which Azure service provides a central hub to discover, assess sizing, estimate costs, and execute server migrations for on-premises infrastructure?**
    
    - **Answer:** **Azure Migrate**.
        
4. **What is the primary role of Azure Site Recovery (ASR)?**
    
    - **Answer:** It acts as a Disaster Recovery as a Service (DRaaS) solution that continuously replicates virtual machines to Azure, allowing automated failover during regional or datacenter outages.
