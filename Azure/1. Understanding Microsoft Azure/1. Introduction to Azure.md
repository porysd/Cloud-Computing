# 1. Introduction to Azure

This section introduces Microsoft Azure, cloud computing fundamentals vs. on-premises infrastructure, key reliability metrics (SLAs), and resource scaling concepts.

**1. On-Premises vs. Cloud Computing**

- **On-Premises:** IT infrastructure hosted, owned, and maintained physically within an organization's facility. Requires high upfront capital expenditure (CapEx) and continuous maintenance.
    
- **Cloud Computing:** On-demand delivery of computing resources (compute, storage, databases, networking) over the internet using a **pay-as-you-go** operational model (OpEx), paying only for what is consumed.
    
- **Microsoft Azure:** A leading public cloud platform offering over 200 integrated services trusted by 95% of Fortune 500 companies.
    

**2. Key Cloud Benefits & Reliability Metrics**

- **Service Level Agreements (SLAs):** Financial and operational commitments made by Azure defining guaranteed uptime levels.
    
    - Common SLA categories: **99%**, **99.9%**, **99.95%**, and **99.99%** (Four Nines = ~52 minutes of downtime per year).
        
- **Global Reliability:** Built-in fault tolerance and regional redundancy allow resources to fail over to alternate geographic regions during catastrophic events.
    
- **Cost Predictability:** Tools like Total Cost of Ownership (TCO) and Azure Pricing Calculators allow organizations to forecast and optimize cloud spending.
    

**3. Types of Resource Scaling**

|**Scaling Type**|**Definition**|**Implementation Method**|**Best Used For**|
|---|---|---|---|
|**Vertical Scaling (Scale Up / Scale Down)**|Adding or removing physical capacity to an existing server (e.g., upgrading RAM or CPU specs).|Upgrading VM instance size (e.g., moving from 2 vCPUs to 8 vCPUs).|Applications requiring higher single-node processing power.|
|**Horizontal Scaling (Scale Out / Scale In)**|Adding or removing identical instances of a resource to distribute workload demand.|Adding additional VM instances behind a Load Balancer via Auto-scaling.|Managing sudden, variable, or unpredictable web traffic spikes.|

**Quick Review Questions**

1. **What is the key difference between vertical scaling and horizontal scaling?**
    
    - **Answer:** Vertical scaling adds or removes RAM/CPUs to an existing server, whereas horizontal scaling adds or removes entire instances/nodes of a server.
        
2. **What does a Service Level Agreement (SLA) guarantee in Microsoft Azure?**
    
    - **Answer:** It defines Microsoft's commitment to service uptime and availability (e.g., 99.9% or 99.99%).
        
3. **Which certification exam aligns directly with these foundational Azure topics?**
    
    - **Answer:** Microsoft Azure Fundamentals (AZ-900).
        
4. **How does the cloud billing model differ from traditional on-premises infrastructure hosting?**
    
    - **Answer:** Cloud computing uses a pay-as-you-go model (paying only for consumed resources) rather than purchasing upfront physical hardware.
