# 2. Azure's Core Components

**Azure Architectural Components & Core Services**

This section covers Microsoft Azure's core management hierarchy—Resources, Resource Groups, Azure Resource Manager (ARM)—and introduces the primary cloud service categories.

**1. Azure Management Hierarchy & Deployment Model**

- **Resource:** The basic building block of Azure representing a deployed service (e.g., a Virtual Machine, SQL database, or Web App). Formally declared as an object inside a JSON template containing four mandatory properties:
    
    - `type`
        
    - `apiVersion`
        
    - `name`
        
    - `location`
        
- **Resource Group:** A mandatory logical container that holds related Azure resources sharing the same lifecycle, administration rules, and security policies.
    
    - _Rule:_ Every Azure resource **must** belong to exactly one Resource Group.
        
    - _Use Case:_ Grouping a Web App, database, and virtual network together to manage, monitor, and delete them as a single unit.
        
- **Azure Resource Manager (ARM):** The central management, deployment, and control plane for Azure. Regardless of whether resources are created via the Azure Portal, CLI, PowerShell, or SDKs, all requests pass through ARM.
    
- **Microsoft Entra ID (formerly Azure Active Directory):** Cloud-based identity and access management (IAM) service. ARM checks permissions against Entra ID to authenticate and authorize user actions before executing any resource deployment or configuration change.
    

**2. Azure Core Service Categories**

|**Category**|**Description**|**Key Product Examples**|
|---|---|---|
|**Compute**|On-demand processing power and execution environments for applications.|Azure Virtual Machines, Azure Container Instances (ACI), Azure Kubernetes Service (AKS)|
|**Storage**|Highly scalable, managed cloud storage solutions for structured, semi-structured, and unstructured data.|Azure Blob Storage, Azure Files, Azure Data Lake Storage|
|**Networking**|Connectivity tools linking cloud resources, on-premises datacenters, and edge locations.|Azure Virtual Network (VNet), VPN Gateway, Azure Content Delivery Network (CDN)|
|**Databases**|Fully managed relational and NoSQL database instances for dynamic data operations.|Azure Cosmos DB, Azure SQL Database, Azure SQL Managed Instance|

**Quick Review Questions**

1. **What are the four mandatory common properties present in every Azure resource JSON definition?**
    
    - **Answer:** `type`, `apiVersion`, `name`, and `location`.
        
2. **Can an Azure resource exist outside of a Resource Group?**
    
    - **Answer:** No. Every resource must be assigned to exactly one Resource Group.
        
3. **What central management service processes all requests to create, modify, or delete Azure resources?**
    
    - **Answer:** Azure Resource Manager (ARM).
        
4. **Which service acts as Azure's cloud-based identity provider to authenticate user requests before ARM executes them?**
    
    - **Answer:** Microsoft Entra ID (formerly Azure Active Directory).
